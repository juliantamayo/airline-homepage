# Airline Homepage

Landing page responsive para una aerolínea ficticia, desarrollada como proyecto de práctica de maquetación web.

El proyecto presenta una página de inicio con una sección principal promocional, ofertas de destinos y un pie de página con enlaces informativos. La interfaz se adapta a diferentes tamaños de pantalla, tanto en dispositivos móviles como en escritorio.

## Vista general

La página incluye:

- Encabezado con logotipo, navegación principal y selector de idioma.
- Sección principal con imagen promocional y llamado a la acción.
- Listado de ofertas de viaje presentadas mediante tarjetas.
- Diseño responsive para dispositivos móviles y pantallas de escritorio.
- Pie de página con redes sociales, servicios y enlaces informativos.
- Interacciones básicas realizadas con JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- Less
- JavaScript

## Estructura del proyecto

```text
airline-homepage/
├── css/        # Estilos del proyecto
├── imgs/       # Imágenes y recursos gráficos
├── js/         # Interacciones con JavaScript
└── index.html  # Página principal
```

## Cómo ejecutar el proyecto

1. Clone el repositorio:

```bash
git clone https://github.com/juliantamayo/airline-homepage.git
```

2. Ingrese a la carpeta del proyecto:

```bash
cd airline-homepage
```

3. Abra el archivo `index.html` en su navegador.

También puede utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto localmente.

## Diseño responsive

La interfaz fue maquetada para ajustarse a diferentes resoluciones:

- En escritorio, las ofertas se muestran distribuidas horizontalmente.
- En dispositivos móviles, el contenido se reorganiza verticalmente.
- El encabezado, los textos, las imágenes y el pie de página se adaptan al ancho disponible.
